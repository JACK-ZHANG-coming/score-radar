## 事故:误杀用户本地后端服务(已恢复)
- 原因:清理测试服务时用了 `pkill -f "node src/index.js"`,该模式同时匹配到用户本地 3000 端口在跑的后端,导致其被杀 → 用户点击页面报「网络异常」/接口无数据。
- 教训(重要):本机禁止用宽泛 pkill 清理服务。测试服务应记下 task_id,用 TaskStop 精确停止;或启动时用独立端口+run_in_background,停止只针对该 task。
- 恢复:已用 run_in_background 在 3000 端口重新拉起后端(含新增 /api/analysis 路由),验证 /api/health ok、classes 200、failures(5班) 200/2批次/30行。
- 环境事实:用户前端并非 5174 dev(未运行),而是走后端 3000 静态托管 web/dist(server/index.js express.static)。改前端后需 npm run build 才在 3000 生效。
