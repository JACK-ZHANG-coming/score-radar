## 成绩记录新增「备注」与「二次订正分」字段（21:22 起）
- 需求：学生成绩记录列表新增两列——「备注」（教师反馈/补充说明，文本过长截断+悬浮提示展示全文，空值显示"—"）、「二次订正分」（学生二次订正后成绩，数字格式与成绩列一致，空值/未订正占位"—"），样式与既有列统一，不影响既有字段、移动端兼顾。
- **后端 DB（server/src/db.js）**：scores 表已存在（52 行），沿用 batch_no 的 ALTER 迁移模式，新增两列：
  - `remark TEXT NOT NULL DEFAULT ''`（空串=无备注）

- **后端 API（server/src/routes/scores.js）**：

  - `SORT_FIELDS` 加 `correction_score: 'correctionScore'`。
  - `emptyForm` 加 `correction_score: null, remark: ''`。
  - 表单：总成绩后加 `二次订正分`（el-input-number 0~600，placeholder「未订正」）+ `备注`（textarea 2行 maxlength 500 show-word-limit）。
  - 列设置 localStorage 兼容：新增列自动追加到已存配置末尾且默认可见（loadColumnConfig 的兼容逻辑覆盖）。
  - `.remark-cell` 样式（inline-block + ellipsis）；`@media (max-width:768px)` 备注 max-width 120px 适配小屏横向滚动。

## 试卷批号搜索改为下拉选择 + 班级级联（21:50 起）

- **后端 server/src/routes/scores.js**：新增 `GET /api/scores/batch-nos?class=xxx`（注册在 `/options` 后）；class 非空时 `SELECT DISTINCT batch_no FROM scores WHERE batch_no != '' AND class = ? ORDER BY batch_no`，否则无 class 过滤取全部；返回 `{ data: { batchNos: string[] } }`。

- **前端 web/src/views/ScoreList.vue**：
