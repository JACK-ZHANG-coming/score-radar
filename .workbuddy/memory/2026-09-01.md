# 2026-09-01 成绩管理后台系统（score-radar）搭建

## 完成内容
- 基于用户上传的两份 Excel 模板（~/Downloads/学生成绩记录.xlsx、考生名单(1).xlsx）搭建成绩管理后台系统
- 前端：web/，Vue 3.5.41 组合式 API + Vite + Element Plus + Pinia + Vue Router，端口 5174
- 后端：server/，Express + better-sqlite3 + JWT + bcryptjs + multer + xlsx，端口 3000
- 表结构：users / students（考号、姓名、班级、年级、学校）/ scores（序号、考号、姓名、学校、班级、考试状态、交卷时间、选择题、电子表格、Access、Python、综合题、总成绩）
- 默认账号 admin/admin123；种子数据：1255 名学生 + 51 条成绩（server/seed/*.csv）
- 导入策略：同考号更新、新考号新增（幂等）

## 关键经验（重要）
- 用户上传的 xlsx 是 **GBK 双重编码**（SheetJS 读出"ÐòºÅ"式乱码），需用 `new TextDecoder('gbk').decode(Buffer.from(s,'latin1'))` 修复；utils/excel.js 中 fixEncoding 已内置
- 交卷时间在源文件中是 Excel 序列号（如 46266.65），需 XLSX.SSF.parse_date_code 转换；存库统一 YYYY-MM-DD HH:mm，否则时间范围字符串比较失效（seed.js 已修复此 bug）
- 本地 Excel 读写走 tencent-local-office-edit skill 的 edsdk.py（端口 39099+）

## 运行方式
- 后端：cd server && npm start（首次启动自动建库+种子）
- 前端：cd web && npm run dev（/api 代理到 3000）
